# คู่มือตั้งค่าการกรอกข้อมูลเอง (ราคาทองพูวง — ไม่บังคับ)

## ✨ วิธีที่ง่ายที่สุด (ตั้งแต่ 30 ก.ย. 2026): อัปโหลดรูป
1. บันทึกรูปราคาที่พูวง (ทอง) หรือ PML (เงิน) โพสต์บน Facebook ลงมือถือ
2. เปิดเว็บ → หน้า **ทองคำ** → การ์ด **"บันทึกราคาร้านจากรูป"** → กด **📷 เลือกรูป / ถ่ายรูป**
3. ระบบอ่านตัวเลขในมือถือ (รูปไม่ถูกส่งไปไหน · ครั้งแรกดาวน์โหลดตัวอ่าน ~4.4 MB) → **ตรวจตัวเลขกับรูป** แก้ได้ทุกช่อง
4. กด **💾 บันทึก** → ระบบส่งเข้าฟอร์มของคุณ และตรวจใน Sheet ว่าบันทึกแล้ว (ขึ้น ✓ ภายในไม่กี่วินาที)
   - ถ้าขึ้น ⚠ ให้กด **"เปิดฟอร์ม (กรอกไว้แล้ว)"** แล้วกดส่งเอง
- รหัสคำถามของฟอร์มอ่านอัตโนมัติทุกรอบ (`scripts/fetch-form-entries.js` → `data/manual-form.json`) — เพิ่มคำถามใหม่ **ต่อท้ายฟอร์มเท่านั้น**
- ราคาทองที่ต่างจาก LBB วันเดียวกันเกิน 15% จะถูกข้าม (กันพิมพ์ผิด/ข้อมูลปลอม) · วันเดียวกันส่งหลายครั้ง = ใช้ค่าล่าสุดที่ไม่ว่างของแต่ละราคา
- คำถามในฟอร์มตอนนี้: วันที่ · ราคาขาย/รับซื้อ (ทองรูปพรรณ ต่อ 1 บาท) · หมายเหตุ · ทองแท่ง ราคาขาย/รับซื้อ · (เงิน PML ราคาขาย/รับซื้อ ต่อ 1 กิโล — เพิ่มต่อท้าย)


## ส่วนที่ 1 — ฟอร์มราคาทองพูวง

### 1. สร้าง Google Form
1. เข้า https://forms.google.com แล้วกด **ฟอร์มเปล่า (Blank)**
2. ตั้งชื่อฟอร์ม เช่น `ราคาทองพูวง`
3. สร้างคำถาม **ตามลำดับนี้เท่านั้น** (ระบบอ่านข้อมูลตามลำดับคอลัมน์):

| ลำดับ | คำถาม | ประเภท | บังคับตอบ |
|---|---|---|---|
| 1 | วันที่ | **วันที่ (Date)** | ✅ |
| 2 | ราคาขาย (กีบ ต่อ 1 บาท) | คำตอบสั้น | ✅ |
| 3 | ราคารับซื้อ (กีบ ต่อ 1 บาท) | คำตอบสั้น | ไม่บังคับ |
| 4 | หมายเหตุ | คำตอบสั้น | ไม่บังคับ |

> 💡 ในคำถามข้อ 2 และ 3 กด ⋮ → **การตรวจสอบคำตอบ (Response validation)** → ตัวเลข → มากกว่า → `1000000`
> เพื่อกันพิมพ์ตัวเลขผิด (ราคาทองลาวต่อบาทเป็นหลักสิบล้านกีบ)

### 2. เชื่อมกับ Google Sheet
1. ในฟอร์ม ไปที่แท็บ **การตอบกลับ (Responses)** → กดไอคอน Sheets สีเขียว → **สร้างสเปรดชีตใหม่**
2. ใน Sheet ที่เปิดขึ้นมา: **ไฟล์ → การตั้งค่า** → ตั้ง
   - **ภาษา/ท้องถิ่น (Locale):** `ไทย` หรือ `ลาว` (สำคัญ! เพื่อให้วันที่เป็นแบบ วัน/เดือน/ปี)
   - **เขตเวลา:** `(GMT+07:00) Bangkok` หรือ `Vientiane`

### 3. เผยแพร่เป็น CSV
1. ใน Sheet: **ไฟล์ → แชร์ → เผยแพร่ไปยังเว็บ (Publish to web)**
2. เลือกแท็บ **การตอบกลับฟอร์ม 1** (ไม่ใช่ "ทั้งเอกสาร")
3. เลือกรูปแบบ **ค่าที่คั่นด้วยจุลภาค (.csv)** → กด **เผยแพร่**
4. คัดลอกลิงก์ที่ได้ หน้าตาประมาณนี้:
   `https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?gid=0&single=true&output=csv`

> 💡 **ถ้ากด "เผยแพร่" แล้วไม่มีอะไรเกิดขึ้น** (Edge บล็อกหน้าต่างยืนยัน): กด **แชร์** → การเข้าถึงทั่วไป **ทุกคนที่มีลิงก์ · ผู้มีสิทธิ์อ่าน** → คัดลอกลิงก์
> แล้วเปลี่ยนท้ายลิงก์จาก `/edit?usp=sharing` เป็น `/export?format=csv` (ได้แท็บแรกของ Sheet — ให้แท็บคำตอบฟอร์มอยู่ซ้ายสุด)

> ⚠️ ลิงก์นี้ใครมีลิงก์ก็เปิดดูได้ — ใส่เฉพาะราคาทอง อย่าใส่ข้อมูลส่วนตัวใน Sheet นี้

### 4. ใส่ลิงก์ในโปรเจกต์
เปิดไฟล์ `config/manual-sources.json` แล้ววางลิงก์ในช่อง `lao_gold_csv_url`:
```json
{
  "lao_gold_csv_url": "https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?gid=0&single=true&output=csv"
}
```
แล้วรัน `node scripts/fetch-all.js` — ราคาจะขึ้นในหน้า **ทองคำ** และ **แดชบอร์ด**

## การใช้งานประจำวัน
- เปิดฟอร์มบนมือถือ (บันทึกลิงก์ฟอร์มไว้ที่หน้าจอหลัก) กรอกราคาพูวงวันละครั้ง
- **กรอกผิด?** แก้ตัวเลขใน Google Sheet ได้เลย หรือกรอกวันเดิมซ้ำ — ระบบใช้ **รายการล่าสุดของวันนั้น**
- แถวที่อ่านไม่ได้ (เช่น ราคาน้อยกว่า 1 ล้านกีบ) จะถูกข้ามและแสดงคำเตือนตอนรันสคริปต์ ไม่ทำให้ระบบพัง

## ค่าพรีเมียมคืออะไร
- **ค่าประมาณ** = ราคาทองแท่งไทย × อัตรา THB→LAK ตลาด
- **พรีเมียม** = ราคาพูวง ÷ ค่าประมาณ (วันเดียวกัน) เช่น 1.03 = ร้านแพงกว่าค่าประมาณ 3%
- **ค่าประมาณปรับพรีเมียม** = ค่าประมาณ × พรีเมียมเฉลี่ยของ 14 วัน**ก่อนหน้า** (ไม่ใช้ราคาวันเดียวกัน เพื่อวัดความแม่นยำได้อย่างซื่อตรง)
- ส่วนต่างความบริสุทธิ์ (ไทย 96.5%) และหน่วย "บาท" ของลาว จะถูกรวมอยู่ในค่าพรีเมียมโดยอัตโนมัติ

## ทดสอบโดยไม่ต้องมี Google Sheet
ใส่ path ของไฟล์ CSV ในเครื่องแทนลิงก์ได้ (ใช้ Git Bash):
```bash
LAO_GOLD_CSV_URL=path/to/sample.csv node scripts/fetch-lao-gold-manual.js
```
