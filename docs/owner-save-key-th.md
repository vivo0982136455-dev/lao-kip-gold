# ให้ "บันทึกราคาได้เฉพาะเจ้าของ" — ขั้นตอนของเจ้าของ (ทาง ข)

> เขียน 5 ต.ค. 2026 · เจ้าของเลือกทาง ข · ฝั่งเว็บและบอท **พร้อมแล้ว** รอเจ้าของทำ 4 ส่วนด้านล่าง (ราว 15 นาที บนโน้ตบุ๊ก)
> ระหว่างที่ยังไม่ทำ เว็บบันทึกผ่านฟอร์มเหมือนเดิมทุกอย่าง

## หลักการ
- สคริปต์เล็ก ๆ ที่ผูกกับ Sheet ของเจ้าของเป็นคนเขียนแถวใหม่ และเขียน **เฉพาะเมื่อได้รับ "รหัสบันทึก" ที่ถูกต้อง**
- รหัสถูกสร้างและเก็บไว้ใน Google ของเจ้าของ (ไม่อยู่ในไฟล์ของเว็บ ไม่อยู่ใน GitHub) เจ้าของพิมพ์รหัสในแอปครั้งเดียวต่อเครื่อง
- ปิดฟอร์มเดิม → คนอื่นส่งราคาเข้ามาไม่ได้อีก
- Sheet ยังเปิด "ทุกคนที่มีลิงก์ **ดูได้**" เหมือนเดิม (บอทอ่านจากตรงนี้ และราคาก็แสดงบนเว็บสาธารณะอยู่แล้ว) — ดูได้ ไม่ได้แปลว่าเขียนได้

⚠️ **รหัสบันทึก: ห้ามวางในแชต ห้ามส่งให้ใคร ห้ามใส่ในไฟล์ของเว็บ** — "ที่อยู่ของสคริปต์" (ลงท้ายด้วย `/exec`) ไม่ใช่ความลับ ส่งให้ Steep ได้

---

## ส่วนที่ 1 — วางสคริปต์ใน Sheet
1. เปิด Google Sheet ที่เก็บคำตอบของฟอร์มราคา
2. เมนูบน: **ส่วนขยาย (Extensions) → Apps Script** — จะเปิดแท็บใหม่
3. ลบโค้ดตัวอย่างในช่องกลางออกให้หมด
4. เปิด https://github.com/vivo0982136455-dev/lao-kip-gold/blob/main/apps-script/save-prices.gs → กดปุ่ม **Copy raw file** (รูปกระดาษสองแผ่น มุมขวาบนของโค้ด)
5. กลับมาแท็บ Apps Script → วาง (Ctrl+V) → กดรูป **แผ่นดิสก์ (บันทึกโครงการ)**

## ส่วนที่ 2 — สร้างรหัสบันทึก
1. ที่แถบเหนือโค้ด มีช่องเลือกชื่อฟังก์ชัน → เลือก **makeKey** → กด **เรียกใช้ (Run)**
2. ครั้งแรก Google จะขอสิทธิ์: **ตรวจสอบสิทธิ์ (Review permissions)** → เลือกบัญชีของเจ้าของ → ถ้าขึ้น "Google ยังไม่ได้ยืนยันแอปนี้" กด **ขั้นสูง (Advanced)** → **ไปที่ … (ไม่ปลอดภัย)** → **อนุญาต (Allow)**
   (คำเตือนนี้ขึ้นกับสคริปต์ส่วนตัวทุกตัว — สคริปต์นี้เป็นของเจ้าของเอง และแตะได้แค่ Sheet แผ่นนี้)
3. ด้านล่างจะมี **บันทึกการดำเนินการ (Execution log)** แสดงบรรทัด `Your key ...: ` ตามด้วยตัวอักษร 24 ตัว = **รหัสบันทึก**
4. จดรหัสไว้ในที่ปลอดภัย (สมุด หรือแอปเก็บรหัสผ่าน) — ถ้าลืม กด makeKey ใหม่ได้เสมอ (รหัสเก่าจะใช้ไม่ได้ทันที)

## ส่วนที่ 3 — เปิดให้เว็บเรียกสคริปต์ได้
1. มุมขวาบน: **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดรูปเฟืองข้าง "เลือกประเภท" → เลือก **เว็บแอป (Web app)**
3. ตั้งค่า:
   - **เรียกใช้ในฐานะ (Execute as):** ฉัน (Me)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone)
     ("ทุกคน" = ใครก็ *เรียก* สคริปต์ได้ แต่สคริปต์เขียนเฉพาะเมื่อรหัสถูก)
4. กด **ทำให้ใช้งานได้ (Deploy)** → คัดลอก **URL ของเว็บแอป** (ขึ้นต้น `https://script.google.com/macros/s/` ลงท้าย `/exec`)
5. **ส่ง URL นี้ให้ Steep ในแชต** (ไม่ใช่ความลับ) → Steep จะใส่ในเว็บ ทดสอบด้วยรหัสผิด (ไม่มีแถวถูกเขียน) แล้วแจ้งกลับ

## ส่วนที่ 4 — หลัง Steep แจ้งว่าเว็บพร้อม
1. เปิดแอป → หน้าทองคำ (หรือ เศรษฐกิจลาว → ยางพารา → ของฉัน) → บันทึกราคาจริง 1 รายการ
2. จะมีช่อง **"รหัสบันทึกของเจ้าของ"** → พิมพ์รหัส 24 ตัว → กด **บันทึก**
   - ขึ้น "✓ บันทึกแล้ว" = สำเร็จ และเครื่องนี้จะจำรหัสไว้ (ครั้งต่อไปไม่ต้องพิมพ์)
   - ขึ้น "✕ รหัสบันทึกไม่ถูกต้อง" = พิมพ์ผิด ลองใหม่ (ไม่มีอะไรถูกบันทึก)
3. เปิด Sheet ดูว่ามีแถวใหม่ → ถ้ามี **ปิดฟอร์มเดิม**: เปิด Google Form → แท็บ **การตอบกลับ (Responses)** → ปิดสวิตช์ **รับคำตอบ (Accepting responses)**
4. ทำข้อ 2 ซ้ำบนเครื่องอื่นที่ใช้บันทึก (มือถือ / โน้ตบุ๊ก)

---

## ถ้ามือถือหาย หรือสงสัยว่ารหัสรั่ว
เปิด Sheet → ส่วนขยาย → Apps Script → เลือก **makeKey** → **เรียกใช้** → ได้รหัสใหม่ รหัสเก่าใช้ไม่ได้ทันที → พิมพ์รหัสใหม่ในเครื่องที่เหลือ
(ในแอป: ปุ่ม **"ลบรหัสออกจากเครื่องนี้"** ใต้ฟอร์มบันทึก ใช้เมื่อจะให้คนอื่นยืมเครื่อง)

## ถ้า Steep แก้โค้ดสคริปต์ในอนาคต
วางโค้ดใหม่ทับ → **Deploy → จัดการการทำให้ใช้งานได้ (Manage deployments) → รูปดินสอ → เวอร์ชัน: เวอร์ชันใหม่ → Deploy** (URL เดิม รหัสเดิม)

## สิ่งที่ทดสอบแล้ว และสิ่งที่ยังทดสอบไม่ได้
- ทดสอบแล้วในเครื่อง (โค้ดสคริปต์ตัวจริงกับ Sheet จำลอง): รหัสถูก → 1 แถว ลงคอลัมน์ถูกทุกช่อง · รหัสผิด / ไม่มีรหัส / ค่าผิดรูป 16 แบบ → ไม่เขียนอะไร (`node tests/save-script.js` 29 ข้อ) · หน้าเว็บ ไทย + ลาว (`tests/states.js` ส่วน 3b)
- **ยังทดสอบไม่ได้จนกว่าเจ้าของทำส่วนที่ 3:** การตอบของ Google จริง (Steep จะทดสอบด้วยรหัสผิด ซึ่งไม่เขียนแถว) และรูปแบบวันที่ที่ Sheet แสดงในแถวแรกที่เจ้าของบันทึกจริง
