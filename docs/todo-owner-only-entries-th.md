# งานที่ต้องให้เจ้าของเลือก: ให้ "บันทึกราคาได้เฉพาะเจ้าของ"

> บันทึกไว้ 2 ต.ค. 2026 (ผลตรวจภายนอก ข้อ P0-3) · สถานะ: **รอเจ้าของเลือกทาง ก หรือ ข**
> ค่าใช้จ่าย: ฟรีทั้งสองทาง

## ปัญหาคืออะไร
ราคาที่บันทึกเอง (ทองร้านพูวง, เงิน PML, ยางที่ขายได้, ที่ดินที่เห็น) ส่งเข้า **Google Form** ของเจ้าของ
แล้วบอทอ่านจาก **Google Sheet** มาแสดงบนเว็บ

- ฟอร์มนี้ **ไม่ต้องล็อกอิน** และที่อยู่ของฟอร์มอยู่ในไฟล์ของเว็บ (เว็บต้องรู้ที่อยู่จึงจะส่งให้ได้) และเว็บเปิดสาธารณะ
- ดังนั้น **คนอื่นที่เปิดดูไฟล์ของเว็บก็ส่งคำตอบเข้าฟอร์มได้** และตัวเลขของเขาอาจขึ้นบนเว็บ
- Sheet เปิดให้ "ทุกคนที่มีลิงก์" อ่านได้ (บอทจึงอ่านได้โดยไม่ต้องมีรหัส)

## ทำไปแล้ว 2 ต.ค. 2026 (ลดความเสียหาย — ยังไม่ได้ปิดช่อง)
บอทตรวจทุกคำตอบเข้มขึ้นก่อนจะขึ้นเว็บ คำตอบที่ไม่ผ่านถูกข้ามพร้อมบันทึกเหตุผล:

| ราคา | ต้องผ่านอะไร |
|---|---|
| ยาง | อยู่ในช่วง 0.15–1.3 เท่าของราคาตลาดไทยชนิดเดียวกัน **ของวันนั้น** คิดเป็นกีบ (2 ต.ค. 2026 ยางก้อนถ้วย ≈ 7,800–68,000 กีบ/กก.) |
| ที่ดิน | นครหลวง: 500–136,000,000 กีบ/ตร.ม. (เทียบจากราคาประเมินทางการ) · แขวงอื่น: 50–136,000,000 |
| ทองร้าน | ห่างจากราคา Lao Bullion Bank วันนั้นไม่เกิน 15% (เหมือนเดิม) |
| ทุกราคา | **วันที่ต้องไม่อยู่ในอนาคต** (เดิมราคาทองลงวันที่อนาคตผ่านได้) |
| ข้อความ | ตัดลิงก์ อีเมล เบอร์โทรออก และยาวไม่เกิน 40 ตัวอักษร |

ผล: คนอื่นใส่ราคา "หลุดโลก" ลิงก์ หรือเบอร์โทรไม่ได้แล้ว **แต่ยังใส่ราคาปลอมที่ดูสมจริงได้**
ทางเดียวที่ปิดได้จริงคือทำให้คนอื่นส่งไม่ได้เลย — ต้องเลือก 1 ใน 2 ทางด้านล่าง

## ทางเลือก

| | **ทาง ก** Sheet ส่วนตัว + ฟอร์มต้องล็อกอิน + กุญแจใน GitHub | **ทาง ข (แนะนำ)** Apps Script + รหัสลับของเจ้าของ |
|---|---|---|
| หลักการ | ฟอร์มรับเฉพาะคนที่ล็อกอิน Google และบอทรับเฉพาะแถวจากอีเมลของเจ้าของ · Sheet ปิดเป็นส่วนตัว · บอทอ่าน Sheet ด้วย "บัญชีบริการ" ของ Google ที่เก็บกุญแจไว้ใน GitHub Secrets | สคริปต์เล็ก ๆ ที่ผูกกับ Sheet เป็นคนรับการบันทึกแทนฟอร์ม และรับเฉพาะเมื่อส่ง **รหัสลับ** มาด้วย · เจ้าของพิมพ์รหัสครั้งเดียวต่อเครื่อง · ปิดฟอร์มเดิม · Sheet ปิดเป็นส่วนตัว |
| เจ้าของต้องทำ | มาก: สร้างโปรเจกต์ใน Google Cloud, เปิด Sheets API, สร้างบัญชีบริการ + ไฟล์กุญแจ, แชร์ Sheet ให้บัญชีนั้น, ใส่กุญแจใน GitHub Secrets, เปลี่ยนตั้งค่าฟอร์ม (ราว 25–30 ขั้น) | น้อยกว่า: เปิด Sheet → ส่วนขยาย → Apps Script → วางโค้ดที่ผมเตรียมให้ → ตั้งรหัสลับ → กด Deploy → ส่งที่อยู่ที่ได้ให้ผม → ปิดฟอร์ม + ตั้ง Sheet เป็นส่วนตัว (ราว 12–15 ขั้น) |
| การบันทึกจากหน้าเว็บ | **ปุ่มบันทึกแตะเดียวใช้ไม่ได้อีก** — เว็บจะเปิดฟอร์มที่กรอกไว้ให้ แล้วเจ้าของต้องกด "ส่ง" เองทุกครั้ง | แตะเดียวเหมือนเดิม และเว็บรู้ผลจริงทันทีว่าบันทึกสำเร็จหรือไม่ |
| รหัส/กุญแจอยู่ที่ไหน | กุญแจอยู่ใน GitHub Secrets (ไม่อยู่ในไฟล์ของเว็บ) | รหัสลับอยู่ใน Apps Script ของเจ้าของ และในเครื่องที่เจ้าของพิมพ์ไว้ (ไม่อยู่ในไฟล์ของเว็บ ไม่อยู่ใน GitHub) |
| ถ้ามือถือหาย | เปลี่ยนรหัสผ่านบัญชี Google | เปลี่ยนรหัสลับใน Apps Script (1 นาที) แล้วพิมพ์ใหม่ในเครื่องที่เหลือ |
| ความเสี่ยงที่เหลือ | ต้องดูแลกุญแจของบัญชีบริการ (หมุนเปลี่ยนเมื่อรั่ว) | ใครรู้รหัสลับก็บันทึกได้ — อย่าบอกใคร อย่าพิมพ์ในแชต |

**คำแนะนำของผม: ทาง ข** — ขั้นตอนน้อยกว่า ไม่ต้องใช้ Google Cloud ไม่เสียปุ่มแตะเดียว และไม่มีกุญแจให้ดูแลใน GitHub

## สิ่งที่ไม่เปลี่ยนไม่ว่าเลือกทางไหน
- การอ่านรูป (OCR) ในหน้าทองคำทำงานเหมือนเดิม
- แถวจริงที่บันทึกไว้แล้วอยู่ครบ
- ตัวตรวจราคาด้านบนยังทำงานต่อ (กันพิมพ์เลขผิดด้วย)

## ขั้นต่อไป
บอก Steep ว่าเลือก **ก** หรือ **ข** → Steep จะเขียนขั้นตอนทีละคลิก (พร้อมภาพว่าปุ่มอยู่ตรงไหน) เตรียมโค้ดให้
และทดสอบกับ Sheet ตัวอย่างในเครื่องก่อน (ไม่ส่งแถวทดสอบเข้า Sheet จริง)

⚠️ **รหัสลับ / กุญแจ: ห้ามวางในแชต ห้ามใส่ในไฟล์ของเว็บ** — ใส่ที่ Google / GitHub ด้วยมือของเจ้าของเท่านั้น
