# วิธีติดตั้งเว็บ "ค่าเงินกีบ & ราคาทอง" เป็นแอป

> ฟรี · ไม่ต้องเข้า Play Store / App Store · ใช้เวลาไม่ถึง 1 นาที · ลบออกได้เหมือนแอปทั่วไป
> ที่อยู่เว็บ: https://vivo0982136455-dev.github.io/lao-kip-gold/

ติดตั้งแล้วได้อะไร
- ไอคอน ₭ สีทองบนหน้าจอ แตะครั้งเดียวเปิดได้เลย เต็มจอ ไม่มีแถบที่อยู่ของเบราว์เซอร์
- กดไอคอนค้าง (มือถือ) มีทางลัดไป อัตราแลกเปลี่ยน · ทองคำ & เงิน · ค่าครองชีพ · เศรษฐกิจลาว
- ไม่มีสัญญาณก็เปิดได้: แสดงข้อมูลชุดล่าสุดที่เคยโหลดไว้ และมีป้าย **ออฟไลน์** สีเหลืองที่แถบบน
  (เมื่อสัญญาณกลับมา ตัวเลขอัปเดตเอง ป้ายหายไป)
- ข้อมูลเป็นชุดเดียวกับเว็บทุกอย่าง แอปคือเว็บเดิมที่เปิดจากไอคอน

## โน้ตบุ๊ก (Microsoft Edge)

วิธีที่ 1 — ปุ่มในเว็บ (ง่ายสุด)
1. เปิดเว็บใน Edge
2. เมนูซ้าย → **ข้อมูล & ตั้งค่า**
3. ที่การ์ด **ติดตั้งเป็นแอป** กดปุ่มสีทอง **📲 ติดตั้งแอป**
4. หน้าต่างเล็กของ Edge ขึ้นมา → กด **Install (ติดตั้ง)**
5. Edge ถามว่าจะปักหมุดที่ไหน → ติ๊ก **Pin to taskbar** (และ **Create Desktop shortcut** ถ้าต้องการ) → กด **Allow**

วิธีที่ 2 — เมนูของ Edge (ถ้าไม่เห็นปุ่มสีทอง)
1. เปิดเว็บใน Edge
2. กด **⋯** (จุดสามจุด มุมขวาบน)
3. ชี้ที่ **Apps (แอป)**
4. กดบรรทัดที่ขึ้นต้นด้วย **Install …** (ชื่อเว็บ หรือ "Install this site as an app" / ภาษาไทย: "ติดตั้ง…") → **Install**

วิธีที่ 3 — ไอคอนท้ายแถบที่อยู่: ถ้าเห็นไอคอนสี่เหลี่ยมเล็ก ๆ มีเครื่องหมาย + ท้ายแถบที่อยู่ (ชี้แล้วขึ้นว่า "App available. Install …") กดไอคอนนั้น → **Install**

## มือถือ Android (Chrome)

วิธีที่ 1 — ปุ่มในเว็บ
1. เปิดเว็บใน Chrome
2. แถบล่าง แตะ **เพิ่มเติม** → **ข้อมูล & ตั้งค่า**
3. ที่การ์ด **ติดตั้งเป็นแอป** แตะปุ่มสีทอง **📲 ติดตั้งแอป** → แตะ **ติดตั้ง (Install)**

วิธีที่ 2 — เมนูของ Chrome
1. เปิดเว็บใน Chrome
2. แตะ **⋮** (จุดสามจุด มุมขวาบน)
3. แตะ **เพิ่มลงในหน้าจอหลัก (Add to Home screen)** — บางรุ่นเขียนว่า **ติดตั้งแอป (Install app)**
4. แตะ **ติดตั้ง (Install)** — ถ้ามีให้เลือกระหว่าง "ติดตั้ง" กับ "สร้างทางลัด" ให้เลือก **ติดตั้ง**
5. รอสักครู่ ไอคอน ₭ จะขึ้นบนหน้าจอหลัก (บางรุ่นอยู่ในลิ้นชักแอป ลากออกมาวางได้)

## iPhone / iPad (Safari)
1. เปิดเว็บใน **Safari** (ต้องเป็น Safari)
2. แตะปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรชี้ขึ้น)
3. เลื่อนลง แตะ **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)** → **เพิ่ม (Add)**

## คำถามที่พบบ่อย
- **ต้องอัปเดตแอปเองไหม?** ไม่ต้อง ทุกครั้งที่เปิดและมีสัญญาณ แอปจะใช้เว็บรุ่นล่าสุดและข้อมูลล่าสุดเอง
- **เปิดค้างไว้ทั้งวัน ตัวเลขเก่าไหม?** เมื่อกลับมาที่แอปหลังผ่านไป 10 นาที แอปอ่านข้อมูลใหม่เอง · บนมือถือลากหน้าจอลงเพื่อรีเฟรชได้เสมอ
- **ลบแอป:** มือถือ — กดไอคอนค้าง → ถอนการติดตั้ง · Edge — เปิดแอป → **⋯** → **App settings** → **Uninstall**
- **กินพื้นที่เท่าไร?** ประมาณ 1.5 MB (สำเนาหน้าเว็บ + ฟอนต์ + ข้อมูลชุดล่าสุด — วัดจริงหลังเปิดครบทุกหน้า 1.3 MB)
