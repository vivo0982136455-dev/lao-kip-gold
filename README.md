# Lao Kip & Gold Dashboard

เว็บส่วนตัวสำหรับดู **ค่าเงินกีบ ราคาทอง (โลก / ไทย / ลาว) และเศรษฐกิจลาว** ในที่เดียว
ฟรีทั้งหมด: เว็บอยู่บน GitHub Pages และดึงข้อมูลอัตโนมัติด้วย GitHub Actions

> สถานะ: เสร็จ Phase 0–5 + หน้าเว็บแบบแอป · ออนไลน์แล้วที่ https://vivo0982136455-dev.github.io/lao-kip-gold/
> (30 ก.ย. 2026: เพิ่มราคาทองลาวจริงจาก LBB + อัตราธนาคาร BCEL อัตโนมัติ · ราคาพูวงเปลี่ยนเป็นไม่บังคับ
>  + หน้าใหม่ "ค่าครองชีพ & การออม": เงินเฟ้อรายเดือน IMF, ราคาสินค้า WFP, ดอกเบี้ยเงินฝาก BCEL — ไม่มีอะไรต้องกรอกเองแล้ว)
> (1 ต.ค. 2026: หน้า "เศรษฐกิจลาว" ใหม่สำหรับนักลงทุน 8 แท็บ — ภาพรวม, GDP & โครงสร้าง, แผนรัฐ 2026–2030 เทียบตัวเลขจริง,
>  การลงทุนต่างชาติรายประเทศ, หนี้สาธารณะรายเจ้าหนี้ + ตารางชำระหนี้ถึง 2032, เงินเฟ้อ & ค่าเงิน, ยางพารา, ที่ดิน)
> (1 ต.ค. 2026: หน้าค่าครองชีพรุ่น 2 — น้ำมันลาว vs ไทย (ราคาไทยวันนี้ + พรุ่งนี้), เงินเฟ้อลาว vs ไทย vs โลก,
>  งบรายเดือน "อยู่ลาวต้องใช้เงินเท่าไร" เทียบกรุงเทพฯ, กล่อง "สิ่งที่ควรรู้ตอนนี้")

เป็นเว็บแบบหน้าเดียว (single-page app) เปลี่ยนหน้าด้วยที่อยู่ `#/...` ไม่ต้อง build ใช้กับ GitHub Pages ได้เลย
บนมือถือเมนูซ้ายจะซ่อน กดปุ่ม ☰ เพื่อเปิด · ธีมมืดเป็นค่าเริ่มต้น

| หน้า | ที่อยู่ | เนื้อหา |
|---|---|---|
| แดชบอร์ด | `#/overview` | สัญญาณค่ากีบวันนี้, ราคาทองลาว (ประมาณการ / ปรับพรีเมียม / พูวง), BOL USD & THB, อัตราตลาด, กราฟ 30 วัน |
| อัตราแลกเปลี่ยน | `#/rates` | ตาราง 7 สกุล (BOL), อัตราธนาคาร BCEL, อัตราตลาด, กราฟเลือกสกุลได้ 7/30/90 วัน |
| ทองคำ & เงิน | `#/gold` | **📷 บันทึกราคาร้านจากรูป** (อ่านรูปพูวง/PML ในเครื่อง → ตรวจ → บันทึกเข้าฟอร์ม), ราคาทองลาวจริง LBB (ต่อ 15 ก. และต่อกรัม), ทองลาวประมาณการ + พรีเมียม, พูวง รูปพรรณ/ทองแท่ง เทียบ LBB, ทองไทย, ทองโลก, กราฟ · **เงิน:** ราคาโลก (USD/ออนซ์, กีบ/กิโล) + ร้าน PML เทียบราคาโลก + กราฟ |
| ค่าครองชีพ & การออม | `#/living` | **สิ่งที่ควรรู้ตอนนี้** (สรุปอัตโนมัติจากข้อมูล), **น้ำมัน: ลาว vs ไทย** (ราคาไทยวันนี้/พรุ่งนี้ แปลงเป็นกีบ + กราฟดีเซลลาว vs น้ำมันดิบโลก), เงินเฟ้อลาว vs ไทย (+ โลก IMF) และ 12 หมวด, ราคาสินค้าจำเป็น 12 รายการ × 17 แขวง, **งบรายเดือน "อยู่ลาวต้องใช้เงินเท่าไร"** (ตะกร้าเดียวกัน ลาว vs กรุงเทพฯ แก้จำนวน/คน/รายได้ได้), "เงิน 1 ล้านกีบ เก็บแบบไหนรักษามูลค่า", ดอกเบี้ยเงินฝาก BCEL vs เงินเฟ้อ |
| เศรษฐกิจลาว | `#/economy` | **8 แท็บสำหรับนักลงทุน** (จำแท็บล่าสุดไว้): ภาพรวม (ตัวเลขสำคัญ 8 ตัว + สิ่งที่ควรรู้ + ควรจับตาอะไร) · GDP & โครงสร้าง (ภาคบริการ/อุตสาหกรรม/เกษตร, การค้า, ดุลบัญชีเดินสะพัด) · แผนรัฐ 2026–2030 (เป้า vs จริง + สถานะอัตโนมัติ) · การลงทุนต่างชาติ (รายปี + รายประเทศ) · หนี้สาธารณะ (รายเจ้าหนี้, ตารางชำระหนี้ถึง 2032, ทำไม/ผลกระทบ/แผน/ทำได้ไหม) · เงินเฟ้อ & ค่าเงิน · ยางพารา (โลก + ไทย เป็นกีบ, รายปี) · ที่ดิน (บอกตรง ๆ ว่ายังไม่มีข้อมูลเปิด) — ทุกตัวเลขมีลิงก์แหล่งที่มา ปีของข้อมูล และป้าย ล่าสุด/เก่า |
| พยากรณ์ & ความแม่นยำ | `#/forecast` | สัญญาณ ▲▼▬, % ทายถูก 30 วัน, ความคลาดเคลื่อนของทองประมาณการ, ประวัติการทาย |
| ข้อมูล & ตั้งค่า | `#/settings` | สลับภาษา ไทย/ลาว, สลับธีม มืด/สว่าง, สถานะทุกแหล่งข้อมูล, เวลาอัปเดตล่าสุด |

**สีบอกประเภทตัวเลข** (ทั้งการ์ดและเส้นกราฟ): 🔵 ทางการ · 🟠 ตลาด · 🟢 ค่าประมาณ (เส้นประเมื่ออยู่กับเส้นอื่น) · 🩷 ธนาคาร (LBB, BCEL) · 🟣 ราคาร้าน (กรอกเอง)
**ขึ้น/ลง:** ป้าย ▲ สีเขียว = ขึ้น · ▼ สีแดง = ลง · ▬ สีเทา = ทรงตัว (สีเขียว/แดงใช้กับตัวเลขและลูกศรเท่านั้น ไม่ใช้กับเส้นกราฟ)
**กราฟ:** เส้นโค้งแบบ monotone (ไม่สร้างยอด/หลุมปลอม), พื้นไล่สีใต้เส้นแรก, ป้ายราคาล่าสุดบนแกนขวา, % เปลี่ยนแปลงของช่วงที่เลือก, ช่วง 7 วัน / 1 เดือน / 3 เดือน / 1 ปี / ทั้งหมด · สีทุกชุดตรวจด้วยเครื่องมือตรวจสีสำหรับคนตาบอดสี
**มือถือ:** แถบเมนูล่าง (หน้าหลัก · อัตรา · ทองคำ · ค่าครองชีพ · เพิ่มเติม)

ข้อควรรู้:
- **LBB:** ใช้ลิงก์ข้อมูลที่เว็บ LBB ใช้เอง (ไม่ได้ประกาศเป็น API) อาจเปลี่ยนได้ · เวลาในข้อมูล LBB เป็น**เวลาเวียงจันทน์**แม้จะติดป้ายว่า UTC (สคริปต์แปลงให้แล้ว) · 1 บาทลาว = 15 กรัม
- **BCEL:** ไม่มีเวลาประกาศ มีแต่ "รอบ" → เก็บวันละ 1 ค่า รอบใหม่ของวันเดียวกันแทนที่รอบเก่า
- **LDB (ราคาพูวง):** มีลิงก์ข้อมูลแต่ต้องใช้รหัสผ่าน (401) → ไม่ใช้ · Facebook → ไม่ใช้ (ตามกฎใน PLAN.md)
- API ทองไทยและ goldprice.dev **ไม่ใช่แหล่งทางการ** อาจหยุดทำงานได้ — ระบบจะเก็บค่าเดิมไว้และติดป้าย "ข้อมูลเก่า"
- ข้อมูล BOL มาจาก mirror ของ AllRatesToday (CC BY 4.0) บางวันอาจช้ากว่าเว็บ BOL 1 วัน
- Chart.js โหลดจาก cdnjs ก่อน ถ้าเครือข่ายบล็อก (เช่น เน็ตบริษัท) จะโหลดสำรองจาก jsDelivr ให้อัตโนมัติ
- IMF API ส่งข้อมูลทุกประเทศมา (~120 KB ต่อตัวชี้วัด) ระบบเลือกเฉพาะลาว (LAO) · IMF SDMX ต้องส่ง header `Accept: application/json` ไม่งั้นได้ XML
- **WFP:** บางแขวงใช้ตัวเลขเดิมซ้ำทุกเดือน (เช่น นครหลวงเวียงจันทน์ตั้งแต่ มิ.ย. 2025) → หน้าเว็บตั้งค่าเริ่มต้นเป็นค่าเฉลี่ยทั้งประเทศ และขึ้นคำเตือนเมื่อราคาไม่ขยับ 6 เดือนขึ้นไป
- **"เงิน 1 ล้านกีบ"** เป็นผลในอดีต ไม่รวมดอกเบี้ย/ค่าธรรมเนียม/ค่ากำเหน็จ · ทอง = ทองโลก × อัตรา BOL · ไม่ใช่คำแนะนำการลงทุน
- **ราคาอาหารไทย (กระทรวงพาณิชย์):** API ช้ามากและบางครั้งตอบ HTTP 500 → ถามทีละรายการ ครั้งละ 3 สัปดาห์ (~25 วินาที/รายการ) รายการที่พลาดลองใหม่อีกครั้งท้ายรอบ · ถ้าพลาดจะเก็บราคาเดิมไว้ + ติดป้าย stale · ค่าเฉลี่ยรายเดือนจะไม่ถูกแทนด้วยค่าที่นับจากวันน้อยกว่า · ใช้ endpoint `gis-product-prices` (แบบพหูพจน์ แบบเอกพจน์ตอบ 404) · รันเฉพาะบางรายการได้: `node scripts/fetch-thai-prices.js pork eggs`
- **ราคาน้ำมันไทย:** บางจากประกาศวันที่แบบ พ.ศ. (30/09/2569) สคริปต์แปลงเป็น ค.ศ. · เทียบลาว (WFP รายเดือน) กับไทย (วันนี้) จึงต่างเวลากัน — หน้าเว็บบอกเดือน/วันของทั้งสองฝั่งเสมอ
- **หนี้รายเจ้าหนี้ (IDS):** หนี้ต่างประเทศของรัฐบาล + รัฐวิสาหกิจที่รัฐค้ำประกัน ณ สิ้นปีล่าสุด · ปีหลังจากนั้นในตารางชำระหนี้ = ยอดครบกำหนดตามสัญญาของหนี้ที่มีอยู่ (ยังไม่นับหนี้ใหม่/การเลื่อนชำระ) · สคริปต์ตรวจว่าผลรวมรายเจ้าหนี้ตรงกับยอดรวม (±2%)
- **FDI รายประเทศ (IMF DIP):** ลาวไม่ได้รายงานเอง ตัวเลขมาจากประเทศผู้ลงทุนที่รายงาน ("mirror") → ประเทศที่ไม่รายงาน เช่น เวียดนาม ไม่อยู่ในตาราง หน้าเว็บเขียนเตือนไว้
- **แผนรัฐ 2026–2030:** เป้าอยู่ใน `data/invest-static.json` (จากข่าว KPL 26 ก.พ. 2026) · สถานะคำนวณในหน้าเว็บ: ถึงเป้า / ใกล้เป้า (ห่าง ≤ 10%) / ห่างเป้า / ไม่มีข้อมูล · GDP ต่อคน (เป้าปี 2030) ใช้ค่าคาดการณ์ IMF ปี 2030
- **ป้าย ล่าสุด/เก่า:** "ล่าสุดจากแหล่ง" = ดึงค่าใหม่ที่สุดที่แหล่งมีสำเร็จ · "ข้อมูลเก่า" = รายปีช้ากว่า 2 ปี หรือรายเดือนช้ากว่า 6 เดือน · "ดึงไม่สำเร็จ" = แสดงค่าเดิม
- **ราคาที่ดิน:** ไม่พบข้อมูลเปิดของทางการ (ตรวจ ต.ค. 2026) → ไม่แสดงตัวเลข แสดงเฉพาะลิงก์เว็บประกาศขาย (ราคาตั้งขาย) พร้อมคำเตือน
- **งบรายเดือน:** ราคาลาว = WFP (ช้า 2–3 เดือน) ราคาไทย = กระทรวงพาณิชย์ แปลงด้วยอัตราตลาด THB→LAK · ยอด "รวม" เทียบเฉพาะรายการที่มีราคาทั้ง 2 ที่ (ไทยไม่มีน้ำตาลทรายแดง) · จำนวนที่แก้จะจำไว้ในเครื่องนั้นเท่านั้น

## สูตรสำคัญ
- **ทองลาวประมาณการ** = ราคาทองแท่งไทย × THB→LAK ตลาด (ต่อ 1 บาทไทย 15.244 ก.)
- **ราคาทองลาวจริง** = ราคาขาย LBB ต่อกรัม × 15 (ต่อ 1 บาทลาว)
- **พรีเมียม** = ราคาขาย LBB ÷ ค่าประมาณ (วันเดียวกัน) — รวมส่วนต่างความบริสุทธิ์และหน่วยบาทไทย/ลาวไว้แล้ว
- **ประมาณการปรับพรีเมียม** = ค่าประมาณ × พรีเมียมเฉลี่ย 14 วัน**ก่อนหน้า** (ไม่ใช้ราคาวันเดียวกัน) · % คลาดเคลื่อนในหน้าพยากรณ์วัดเทียบ LBB
- **ราคาไทยเป็นกีบ** = ราคาบาท × THB→LAK ตลาด · **ลาวเทียบไทย %** = (ลาว − ไทย) ÷ ไทย × 100 (บวก = ลาวแพงกว่า)
- **ราคาอาหารไทยต่อวัน** = (ต่ำสุด + สูงสุด) ÷ 2 ของวันนั้น (ข้าวสารประกาศต่อ 15 กก. → หาร 15)
- **ดอกเบี้ยหลังหักเงินเฟ้อ** = (1 + ดอกเบี้ย) ÷ (1 + เงินเฟ้อ) − 1
- **ราคายางโลก USD/กก.** = ราคา IMF (เซนต์สหรัฐต่อปอนด์) × 2.20462 ÷ 100 · เป็นกีบ = × อัตรา BOL เฉลี่ยของเดือน/ปีนั้น (ก่อนมีข้อมูล BOL ใช้อัตราเฉลี่ยรายปีของธนาคารโลก)
- **กีบอ่อนค่าเทียบปีก่อน (%)** = (อัตรา BOL USD เฉลี่ยเดือนนี้ ÷ เดือนเดียวกันปีก่อน − 1) × 100
- **สัญญาณค่ากีบ**: ทุกวันทำการ ก่อน BOL ประกาศ → ดูอัตราตลาดวันนี้เทียบวันก่อน → บันทึก ▲▼▬ (แก้ย้อนหลังไม่ได้)
  เมื่อ BOL ประกาศ → เทียบค่ากลาง (ซื้อ+ขาย)/2 กับวันประกาศก่อนหน้า → ถูก/ผิด · เปลี่ยนน้อยกว่า 0.02% = ทรงตัว
- **% ความแม่นยำ** คำนวณในหน้าเว็บจากไฟล์ประวัติที่บันทึกไว้เท่านั้น ไม่มีตัวเลขตายตัว

## วิธีรันในเครื่อง

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 20 ขึ้นไป เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์:

```bash
node scripts/fetch-all.js        # ดึงข้อมูลทุกแหล่ง + สร้างไฟล์สรุป + ข้อมูลช่วงยาว + อัปเดตสัญญาณค่ากีบ
node scripts/fetch-economy.js    # ดึงข้อมูลเศรษฐกิจรายปี + รายเดือน (สัปดาห์ละครั้งก็พอ)
node scripts/fetch-prices.js     # ดึงราคาสินค้า WFP (ไฟล์ ~7 MB)
node scripts/check-data.js       # ตรวจไฟล์ข้อมูล: ไม่มีแถวซ้ำ, ค่าถูกต้อง
node scripts/serve.js            # เปิดเว็บ แล้วเข้า http://localhost:8080 (กด Ctrl+C เพื่อหยุด)
```

> ⚠️ ห้ามเปิด `index.html` ด้วยการดับเบิลคลิก เพราะเบราว์เซอร์จะไม่ยอมให้อ่านไฟล์ข้อมูล ให้ใช้ `serve.js`

### ทดสอบ
- **แหล่งข้อมูลพัง:** `GOLD_THAI_URL=https://invalid.example node scripts/fetch-all.js` (ใช้ Git Bash)
  → เฉพาะทองไทยเป็น FAIL + ป้ายข้อมูลเก่า แหล่งอื่นยังปกติ
  ตัวแปรที่ใช้ได้: `BOL_URL`, `GOLD_WORLD_URL`, `GOLD_WORLD_BACKUP_URL`, `GOLD_THAI_URL`, `FX_MARKET_URL`, `BOL_BACKFILL_URL`, `GOLD_LBB_URL`, `LBB_BACKFILL_URL`, `BCEL_URL`, `BCEL_DEPOSIT_URL`, `LAO_GOLD_CSV_URL`
- **ทดสอบโดยไม่แตะข้อมูลจริง:** `DATA_DIR=<โฟลเดอร์ทดสอบ>` เปลี่ยนที่เก็บข้อมูล · `SITE_ROOT=<โฟลเดอร์>` ให้ `serve.js` เปิดเว็บจากโฟลเดอร์อื่น
- **จำลองเวลา (สัญญาณค่ากีบ):** `NOW=2026-09-29T08:00:00+07:00 node scripts/update-forecast.js`

## รูปแบบข้อมูล

ทุกค่าใช้รูปแบบเดียวกัน:
```json
{ "source": "bol", "metric": "USD_LAK_buy", "value": 22329, "unit": "LAK per USD",
  "fetched_at": "2026-09-29T11:08:58Z", "source_date": "2026-09-28" }
```
- ค่าซ้ำ (metric + source_date เดิม) จะไม่ถูกเพิ่มใน history · ราคาพูวงสร้าง history ใหม่จาก Sheet ทุกครั้ง (แก้ใน Sheet ได้)
- ไฟล์จะถูกเขียนใหม่ **เฉพาะเมื่อค่าเปลี่ยน** เพื่อให้ GitHub commit เฉพาะตอนมีข้อมูลใหม่

## ขั้นตอนขึ้น GitHub (ทำแล้ว 29 ก.ย. 2026 — เก็บไว้เป็นบันทึก)

1. สมัคร/ล็อกอิน https://github.com แล้วกด **New repository** (ตั้งเป็น Public เพื่อใช้ GitHub Pages ฟรี)
2. ในโฟลเดอร์นี้ พิมพ์:
   ```bash
   git add .
   git commit -m "Lao Kip & Gold dashboard"
   git branch -M main
   git remote add origin https://github.com/<ชื่อคุณ>/<ชื่อ-repo>.git
   git push -u origin main
   ```
3. บน GitHub: **Settings → Actions → General → Workflow permissions** เลือก **Read and write permissions**
4. **Actions → Fetch data → Run workflow** และ **Fetch economy data → Run workflow** เพื่อทดสอบ
5. **Settings → Pages** → Source: *Deploy from a branch* → Branch `main` / `(root)`

หมายเหตุ: ตาราง cron ของ GitHub อาจเริ่มช้ากว่ากำหนด 10–30 นาทีในบางช่วง
