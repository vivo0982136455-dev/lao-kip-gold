- **ติดตั้งเป็นแอป (service worker):** `sw.js` ถามเครือข่ายก่อนเสมอ (ตัวเลขจึงไม่เก่ากว่าที่จำเป็น) · สำเนาในเครื่องใช้เมื่อไม่มีสัญญาณ หรือช้าเกิน 4 วินาที แล้วหน้าเว็บขึ้นป้าย "ออฟไลน์" และลองใหม่เองทุก 1 นาที · แอปที่เปิดค้างไว้จะอ่านข้อมูลใหม่เองเมื่อกลับมาที่หน้าจอหลังผ่านไป 10 นาที (ไม่ทำระหว่างที่กำลังกรอกฟอร์ม) · ไม่แตะคำขอไป Google Form/Sheet และไฟล์ OCR · ฟอนต์และ Chart.js เก็บสำเนาได้เพราะแท็กมี `crossorigin` · ถ้าต้องปิด: วิธีอยู่ในหัวไฟล์ `sw.js` · **ทดสอบใน Edge/Chrome จริง** (ตัวดูเว็บของ Claude ลงทะเบียน service worker ไม่ได้)
- **เปิดเร็วบนมือถือ:** `index.html` มีบรรทัด `<link rel="modulepreload">` ของทุกไฟล์ใน `js/` (สร้างโดย `scripts/update-preload.js`) เบราว์เซอร์จึงขอไฟล์ทั้งหมดพร้อมกัน ไม่ต้องไล่ทีละชั้น · ลืมรันสคริปต์หลังเพิ่มไฟล์ เว็บยังทำงานปกติ แค่ไฟล์นั้นโหลดช้ากว่าเล็กน้อย
- **กราฟ:** ค่าของจุดที่แตะแสดงใน "แถบค่า" เหนือกราฟ ไม่ใช่กล่องลอยทับเส้น (บนมือถือกล่องเคยบังข้อมูล) · แตะที่อื่นเพื่อกลับไปค่าล่าสุด · แตะชื่อเส้นเพื่อซ่อน/แสดงเส้น · เส้นโค้งแบบ monotone (ไม่สร้างยอด/หลุมที่ข้อมูลไม่มี) จุดกลมแสดงเฉพาะจุดล่าสุด ยกเว้นเส้นที่มีข้อมูลห่าง ๆ (ราคากรอกเอง) จะแสดงทุกจุด · กราฟที่แกนเป็นรายวันแต่มีค่าเฉพาะบางวัน (ราคาน้ำมันทางการ): ตัวเลือก `snap` ทำให้การแตะวิ่งไปหาจุดจริงที่ใกล้ที่สุด และ `gap` ลากเส้นจุดข้ามช่วงที่ไม่มีข้อมูลนานเกินกำหนด · หน่วยเป็นคำอยู่ที่ `unit_names` ใน `i18n/*.json` · ในตาราง ค่าคาดการณ์/เป้าหมายไม่ซ้ำกับปีของข้อมูลจริง และเป้าของแผนแสดงเฉพาะปี 2026–2030
- **งบรายเดือน:** ราคาลาว = WFP (ช้า 2–3 เดือน) ยกเว้นน้ำมัน = ราคาทางการนครหลวงล่าสุด · ราคาไทย = กระทรวงพาณิชย์ แปลงด้วยอัตรากลางอ้างอิง (API) THB→LAK · ยอด "รวม" เทียบเฉพาะรายการที่มีราคาทั้ง 2 ที่ (ไทยไม่มีน้ำตาลทรายแดง) · จำนวนที่แก้จะจำไว้ในเครื่องนั้นเท่านั้น

## สูตรสำคัญ
- **ทองลาวประมาณการ** = ราคาทองแท่งไทย × THB→LAK อัตรากลางอ้างอิง (API) (ต่อ 1 บาทไทย 15.244 ก.)
- **ราคาทองลาวจริง** = ราคาขาย LBB ต่อกรัม × 15 (ต่อ 1 บาทลาว)
- **พรีเมียม** = ราคาขาย LBB ÷ ค่าประมาณ (วันเดียวกัน) — รวมส่วนต่างความบริสุทธิ์และหน่วยบาทไทย/ลาวไว้แล้ว
- **ประมาณการปรับพรีเมียม** = ค่าประมาณ × พรีเมียมเฉลี่ย 14 วัน**ก่อนหน้า** (ไม่ใช้ราคาวันเดียวกัน) · % คลาดเคลื่อนในหน้าพยากรณ์วัดเทียบ LBB
- **ราคาไทยเป็นกีบ** = ราคาบาท × THB→LAK อัตรากลางอ้างอิง (API) · **ลาวเทียบไทย %** = (ลาว − ไทย) ÷ ไทย × 100 (บวก = ลาวแพงกว่า)
- **ราคาอาหารไทยต่อวัน** = (ต่ำสุด + สูงสุด) ÷ 2 ของวันนั้น (ข้าวสารประกาศต่อ 15 กก. → หาร 15)
- **ดอกเบี้ยหลังหักเงินเฟ้อ** = (1 + ดอกเบี้ย) ÷ (1 + เงินเฟ้อ) − 1
- **ค่าแรงขั้นต่ำต่อเดือนเป็น USD** = จำนวนต่อเดือนในเงินท้องถิ่น ÷ อัตรากลางอ้างอิง (API) (เงินท้องถิ่นต่อ 1 USD) · จำนวนต่อเดือน = รายชั่วโมง × 173.33 · รายวัน × 26 · หรือจำนวนที่กฎหมายระบุเอง · เป็นกีบ = USD × อัตรากลางอ้างอิง USD→LAK (API) · **เท่าของลาว** = USD ของประเทศนั้น ÷ USD ของลาว
- **อำนาจซื้อของค่าแรงขั้นต่ำลาว** = ดัชนีราคาเดือนที่ขึ้นค่าแรงครั้งล่าสุด ÷ ดัชนีราคาเดือนล่าสุด − 1 (ติดลบ = ซื้อของได้น้อยลง) · **ซื้อน้ำมันได้กี่ลิตร** = ค่าแรงขั้นต่ำต่อเดือน ÷ ราคาเบนซินธรรมดาหน้าปั๊มของประเทศนั้น
- **ราคายางลาวที่ด่านจีน USD/กก.** = มูลค่านำเข้า (CIF, USD) ÷ น้ำหนักสุทธิ (กก.) ของ HS 4001 ที่จีนนำเข้าจากลาวทั้งปี · เป็นกีบ = × อัตราเฉลี่ยของปีนั้น
- **ราคาเฉลี่ยส่งออก/นำเข้ายางของแต่ละประเทศ USD/กก.** = มูลค่า (USD) ÷ น้ำหนักสุทธิ (กก.) ของปีนั้น เฉพาะส่วนที่มีน้ำหนัก (ส่งออก = FOB ที่ด่านผู้ขาย · นำเข้า = CIF รวมค่าขนส่ง)
- **ราคายางที่บันทึกเอง เทียบไทย %** = ราคาที่ขายได้ (กีบ/กก.) ÷ ราคาตลาดไทยชนิดเดียวกันของวันนั้น (บาท × อัตรากลางอ้างอิง THB→LAK (API)) × 100 — ยางก้อนถ้วยของไทยเป็นราคาเนื้อยางแห้ง 100% ยางเปียกจึงต่ำกว่าเป็นปกติ
  · ตลาดที่ใช้เทียบ = ตลาดกลางที่ใกล้แขวงนั้นที่สุด: บ่อแก้ว หลวงน้ำทา อุดมไซ ผ้งสาลี ไซยะบูลี หลวงพระบาง → **เชียงราย** · แขวงอื่น → **หนองคาย** (วันเดียวกัน หรือวันทำการล่าสุดก่อนหน้า) ถ้าไฟล์รายวันยังไม่มี ใช้ราคากระทรวงพาณิชย์ไทยเหมือนเดิม
- **ราคายางลาวที่ด่านเวียดนาม USD/กก.** = มูลค่า (USD) ÷ น้ำหนัก (ตัน × 1,000) ของแถว "Cao su" ที่นำเข้าจากลาวในเดือนนั้น (ตาราง 5N ของศุลกากรเวียดนาม) · ยอดทั้งปี = คอลัมน์ "สะสมตั้งแต่ต้นปี" ของไฟล์เดือนล่าสุดของปีนั้น
- **ราคายางแต่ละประเทศเป็น USD/กก.** = ราคาเงินท้องถิ่น ÷ อัตรากลางอ้างอิง (API)ของวันนั้น (บาท ริงกิต เปโซ) · เซี่ยงไฮ้: หยวน/ตัน ÷ อัตรา ÷ 1,000
- **ราคาที่ดินที่บันทึกเอง กีบ/ตร.ม.** = ราคารวม (แปลงเป็นกีบ) ÷ เนื้อที่ (ตร.ม.; 1 ไร่ = 1,600 · 1 เฮกตาร์ = 10,000)
- **ราคายางโลก USD/กก.** = ราคา IMF (เซนต์สหรัฐต่อปอนด์) × 2.20462 ÷ 100 · เป็นกีบ = × อัตรา BOL เฉลี่ยของเดือน/ปีนั้น (ก่อนมีข้อมูล BOL ใช้อัตราเฉลี่ยรายปีของธนาคารโลก)
- **กีบอ่อนค่าเทียบปีก่อน (%)** = (อัตรา BOL USD เฉลี่ยเดือนนี้ ÷ เดือนเดียวกันปีก่อน − 1) × 100
- **เส้นคาดการณ์ของตัวเลขที่เป็นจำนวน (GDP, GDP ต่อคน)** = ค่าจริงปีล่าสุด × (IMF ปีนั้น ÷ IMF ปีเดียวกับค่าจริง) — ไม่เอาระดับของ IMF มาต่อกับค่าของธนาคารโลกตรง ๆ · ตัวเลขที่เป็นอัตรา (%) ใช้ตามที่ IMF ให้
- **แท็บเทียบเพื่อนบ้าน:** ปีของการ์ด = ปีล่าสุดที่ลาวมีข้อมูล · ประเทศอื่นใช้ค่าของปีเดียวกัน ถ้าไม่มีใช้ปีล่าสุดก่อนหน้าพร้อมเครื่องหมาย ⚠ · อันดับนับเฉพาะประเทศที่มีข้อมูลปีเดียวกัน · ส่งออก % ของ GDP = ส่งออกสินค้า ÷ GDP ของปีเดียวกัน
- **สัญญาณค่ากีบ**: ทุกวันทำการ ก่อน BOL ประกาศ → ดูอัตรากลางอ้างอิง (API) วันนี้เทียบวันก่อน → บันทึก ▲▼▬ (แก้ย้อนหลังไม่ได้)
  เมื่อ BOL ประกาศ → เทียบค่ากลาง (ซื้อ+ขาย)/2 กับวันประกาศก่อนหน้า → ถูก/ผิด · เปลี่ยนน้อยกว่า 0.02% = ทรงตัว
- **% ความแม่นยำ** คำนวณในหน้าเว็บจากไฟล์ประวัติที่บันทึกไว้เท่านั้น (90 วันล่าสุด) ไม่มีตัวเลขตายตัว · **แสดงเมื่อตรวจผลแล้วอย่างน้อย 20 ครั้ง** ต่ำกว่านั้นขึ้นคำว่า "กรณียังไม่พอ" · ตัวเทียบ "ทายทิศเดียวทุกวัน" = สัดส่วนของทิศที่เกิดบ่อยที่สุด

## วิธีรันในเครื่อง

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 20 ขึ้นไป เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์:

```bash
node scripts/fetch-all.js        # ดึงข้อมูลทุกแหล่ง + สร้างไฟล์สรุป + ข้อมูลช่วงยาว + อัปเดตสัญญาณค่ากีบ
node scripts/fetch-economy.js    # ดึงข้อมูลเศรษฐกิจรายปี + รายเดือน (สัปดาห์ละครั้งก็พอ)
node scripts/fetch-prices.js     # ดึงราคาสินค้า WFP (ไฟล์ ~7 MB)
node scripts/fetch-rubber-world.js  # ยางพาราทั้งโลก (~2.5 นาที; ครั้งแรกดาวน์โหลดไฟล์ FAO 46 MB)
node scripts/fetch-rubber-daily.js  # ราคายางรายวัน: หนองคาย/เชียงราย, มาเลเซีย, เซี่ยงไฮ้ (เติม months=14 = ย้อนหลัง 14 เดือน)
```

### ทดสอบ
- **ทดสอบหน้าเว็บในเบราว์เซอร์จริง** (ต้องมี Edge หรือ Chrome; Node 22 ขึ้นไป):
  ```bash
  node tests/all.js            # ทุกอย่างในเครื่อง ~30 นาที (เติม quick = ตรวจ 23 หน้าจอแทน 184)
  node tests/calc.js           # กติกาและสูตรด้วยตัวเลขตายตัว (ไม่ใช้เบราว์เซอร์ ไม่กี่วินาที)
  node tests/own-prices.js     # ตัวตรวจคำตอบของแบบฟอร์มราคา กับ Sheet ตัวอย่าง (ไม่แตะฟอร์มจริง)
  node tests/bol-route.js      # อัตรา BOL: อ่านตรง / ทางสำรอง กับหน้าเว็บที่บันทึกไว้ (ไม่ดาวน์โหลดอะไร)
  node tests/data-check.js     # ตัวตรวจข้อมูลจับตัวเลขผิดได้จริงไหม (ทำลายสำเนาข้อมูล 29 แบบ)
  node tests/screens.js quick  # เฉพาะหน้าจอ: ไทย มืด มือถือ (~1 นาที)
  node tests/live.js           # เว็บจริงบน GitHub Pages หลัง push 2–3 นาที (รวมจำลองสัญญาณหลุด)
  ```
  `calc.js` ตรวจ: สถานะเป้าแผนรัฐ (ถึง/ใกล้/ห่าง, ค่าก่อนเริ่มแผน, ข้อมูลเก่า), "ตัวเลขใหม่ที่สุดที่เว็บมี", ขีดจำกัดและการตัดข้อความของบอทกับของหน้าเว็บต้องเหมือนกัน, ตัวแตกไฟล์ .7z (3 วิธีบีบอัด + ไฟล์เสียต้องถูกปฏิเสธ), การอ่านตารางของ UNCTAD
  ตรวจ: ไม่มีการเลื่อนซ้าย-ขวา, ไม่มีอะไรล้นจอ **หรือล้นกรอบ/การ์ดของตัวเอง** (ตัวเลข + หน่วยที่ยาวเกินกรอบเคยล้นทั้งที่ยังอยู่ในจอ), ไม่มีคำว่า undefined / NaN / `{ตัวแปร}` ที่ไม่ถูกแทนค่า, กราฟถูกวาดครบ, ไม่มี error ใน console, ติดตั้งเป็นแอปได้, ออฟไลน์เปิดได้พร้อมป้าย · แต่ละชุดมีเวลาจำกัดและทุกคำสั่งถึงเบราว์เซอร์มีเวลาตอบ 90 วินาที — เบราว์เซอร์ที่ค้างจะทำให้ทดสอบ "ไม่ผ่าน" แทนที่จะรอไม่จบ · รูปหน้าจอเก็บใน `tests/shots/` (ไม่ commit) · ฟอร์มบันทึกราคาถูกเปิดและกรอก แต่**ไม่กดบันทึก** และคำขอไป Google ถูกบล็อกระหว่างทดสอบ จึงไม่มีแถวปลอมเข้า Sheet
- **แหล่งข้อมูลพัง:** `GOLD_THAI_URL=https://invalid.example GOLD_THAI_BACKUP_URL=https://invalid.example node scripts/fetch-all.js` (ใช้ Git Bash)
  → เฉพาะทองไทยเป็น FAIL + ป้ายข้อมูลเก่า แหล่งอื่นยังปกติ
  ตัวแปรที่ใช้ได้: `BOL_PAGE_URL` (โฟลเดอร์ของหน้า BOL ที่บันทึกไว้: `today.html`, `2026-10-02.html`), `BOL_URL` (สำเนา), `GOLD_WORLD_URL`, `GOLD_WORLD_BACKUP_URL`, `GOLD_THAI_URL`, `GOLD_THAI_BACKUP_URL`, `FX_MARKET_URL`, `BOL_BACKFILL_URL`, `GOLD_LBB_URL`, `LBB_BACKFILL_URL`, `BCEL_URL`, `BCEL_DEPOSIT_URL`, `LAO_GOLD_CSV_URL`, `RAOT_URL`, `LGM_URL`, `SHFE_URL`, `FUEL_LAO_NOTICES_URL`, `FUEL_LAO_PRICES_URL`, `ILO_URL`, `REPORT_WATCH_WDS_URL`, `BOL_EXTERNAL_URL`, `BOL_INFLATION_URL` · `FUEL_LAO_PDF_DIR=<โฟลเดอร์>` = อ่านประกาศน้ำมันจากไฟล์ PDF ที่ดาวน์โหลดไว้แล้ว
- **ทดสอบโดยไม่แตะข้อมูลจริง:** `DATA_DIR=<โฟลเดอร์ทดสอบ>` เปลี่ยนที่เก็บข้อมูล · `SITE_ROOT=<โฟลเดอร์>` ให้ `serve.js` เปิดเว็บจากโฟลเดอร์อื่น
- **จำลองเวลา (สัญญาณค่ากีบ):** `NOW=2026-09-29T08:00:00+07:00 node scripts/update-forecast.js`

## รูปแบบข้อมูล

ทุกค่าใช้รูปแบบเดียวกัน:
```json
{ "source": "bol", "metric": "USD_LAK_buy", "value": 22329, "unit": "LAK per USD",
  "fetched_at": "2026-09-29T11:08:58Z", "source_date": "2026-09-28" }
```
- ค่าซ้ำ (metric + source_date เดิม) จะไม่ถูกเพิ่มใน history · ราคาพูวงสร้าง history ใหม่จาก Sheet ทุกครั้ง (แก้ใน Sheet ได้)
- ไฟล์จะถูกเขียนใหม่ **เฉพาะเมื่อค่าเปลี่ยน** เพื่อให้ GitHub commit เฉพาะตอนมีข้อมูลใหม่

## ขั้นตอนขึ้น GitHub (ทำแล้ว 29 ก.ย. 2026 — เก็บไว้เป็นบันทึก)

1. สมัคร/ล็อกอิน https://github.com แล้วกด **New repository** (ตั้งเป็น Public เพื่อใช้ GitHub Pages ฟรี)
2. ในโฟลเดอร์นี้ พิมพ์:
   ```bash
   git add .
   git commit -m "Lao Kip & Gold dashboard"
   git branch -M main
   git remote add origin https://github.com/<ชื่อคุณ>/<ชื่อ-repo>.git
   git push -u origin main
   ```
3. บน GitHub: **Settings → Actions → General → Workflow permissions** เลือก **Read and write permissions**
4. **Actions → Fetch data → Run workflow** และ **Fetch economy data → Run workflow** เพื่อทดสอบ
5. **Settings → Pages** → Source: *Deploy from a branch* → Branch `main` / `(root)`

หมายเหตุ: ตาราง cron ของ GitHub อาจเริ่มช้ากว่ากำหนด 10–30 นาทีในบางช่วง
