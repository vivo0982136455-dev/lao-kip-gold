# Lao Kip & Gold Dashboard

เว็บส่วนตัวสำหรับดู **ค่าเงินกีบ ราคาทอง (โลก / ไทย / ลาว) และเศรษฐกิจลาว** ในที่เดียว
ฟรีทั้งหมด: เว็บอยู่บน GitHub Pages และดึงข้อมูลอัตโนมัติด้วย GitHub Actions

> สถานะ: เสร็จ Phase 0–5 + หน้าเว็บแบบแอป · ออนไลน์แล้วที่ https://vivo0982136455-dev.github.io/lao-kip-gold/
> (30 ก.ย. 2026: เพิ่มราคาทองลาวจริงจาก LBB + อัตราธนาคาร BCEL อัตโนมัติ · ราคาพูวงเปลี่ยนเป็นไม่บังคับ
>  + หน้าใหม่ "ค่าครองชีพ & การออม": เงินเฟ้อรายเดือน IMF, ราคาสินค้า WFP, ดอกเบี้ยเงินฝาก BCEL — ไม่มีอะไรต้องกรอกเองแล้ว)
> (1 ต.ค. 2026: หน้า "เศรษฐกิจลาว" ใหม่สำหรับนักลงทุน 8 แท็บ — ภาพรวม, GDP & โครงสร้าง, แผนรัฐ 2026–2030 เทียบตัวเลขจริง,
>  การลงทุนต่างชาติรายประเทศ, หนี้สาธารณะรายเจ้าหนี้ + ตารางชำระหนี้ถึง 2032, เงินเฟ้อ & ค่าเงิน, ยางพารา, ที่ดิน)
> (1 ต.ค. 2026: หน้าค่าครองชีพรุ่น 2 — น้ำมันลาว vs ไทย (ราคาไทยวันนี้ + พรุ่งนี้), เงินเฟ้อลาว vs ไทย vs โลก,
>  งบรายเดือน "อยู่ลาวต้องใช้เงินเท่าไร" เทียบกรุงเทพฯ, กล่อง "สิ่งที่ควรรู้ตอนนี้")
> (1 ต.ค. 2026 รอบบ่าย: **ยางพารา 5 มุมมอง** — ราคาตลาด · ลาวรายแขวง · อาเซียน + จีน · โลกและ 10 อันดับผู้ขาย/ผู้ซื้อ · ราคาที่คุณขายได้เอง ·
>  **แท็บที่ดินใหม่** ทุกแขวง เน้นนครหลวงเวียงจันทน์ + หลวงพระบาง · **บันทึกราคายาง/ที่ดินที่เห็นเอง**จากหน้าเว็บ ·
>  **ติดตั้งเป็นแอป**ได้ (ไอคอนบนหน้าจอมือถือ/คอมพิวเตอร์ + เปิดได้ตอนไม่มีสัญญาณ) → วิธีติดตั้ง [docs/install-app-th.md](docs/install-app-th.md))
> (2 ต.ค. 2026: **ยางพารา มุมมองที่ 6 "ลาวขายให้ใคร"** — ยางลาวไปจีนและเวียดนามเกือบทั้งหมด ไทยแทบไม่ซื้อ · ราคาที่ด่านรายปี/รายเดือน ·
>  ตลาดกลางยางไทยที่ติดลาว (หนองคาย เชียงราย) รายวันเป็นราคาอ้างอิง · ตาราง**ราคายางล่าสุดของแต่ละประเทศ** ลาว · อาเซียน · จีน · โลก ·
>  **แท็บใหม่ "ประชากร"** และ **"นโยบายรัฐ"** (หน้าเศรษฐกิจมี 10 แท็บ) · เมนูมือถือเหลือปุ่มเดียว ("เพิ่มเติม" ที่แถบล่าง))

## หน้าเว็บ (7 หน้า)

เป็นเว็บแบบหน้าเดียว (single-page app) เปลี่ยนหน้าด้วยที่อยู่ `#/...` ไม่ต้อง build ใช้กับ GitHub Pages ได้เลย
บนมือถือเมนูซ้ายจะซ่อน เปิดด้วยปุ่ม "เพิ่มเติม" ที่แถบล่าง (ปิดด้วย ✕ ในเมนู หรือแตะพื้นหลัง) · ธีมมืดเป็นค่าเริ่มต้น

| อัตราแลกเปลี่ยน | `#/rates` | ตาราง 7 สกุล (BOL), อัตราธนาคาร BCEL, อัตราตลาด, กราฟเลือกสกุลได้ 7/30/90 วัน |
| ทองคำ & เงิน | `#/gold` | **📷 บันทึกราคาร้านจากรูป** (อ่านรูปพูวง/PML ในเครื่อง → ตรวจ → บันทึกเข้าฟอร์ม), ราคาทองลาวจริง LBB (ต่อ 15 ก. และต่อกรัม), ทองลาวประมาณการ + พรีเมียม, พูวง รูปพรรณ/ทองแท่ง เทียบ LBB, ทองไทย, ทองโลก, กราฟ · **เงิน:** ราคาโลก (USD/ออนซ์, กีบ/กิโล) + ร้าน PML เทียบราคาโลก + กราฟ |
| ค่าครองชีพ & การออม | `#/living` | **สิ่งที่ควรรู้ตอนนี้** (สรุปอัตโนมัติจากข้อมูล), **น้ำมัน: ลาว vs ไทย** (ราคาไทยวันนี้/พรุ่งนี้ แปลงเป็นกีบ + กราฟดีเซลลาว vs น้ำมันดิบโลก), เงินเฟ้อลาว vs ไทย (+ โลก IMF) และ 12 หมวด, ราคาสินค้าจำเป็น 12 รายการ × 17 แขวง, **งบรายเดือน "อยู่ลาวต้องใช้เงินเท่าไร"** (ตะกร้าเดียวกัน ลาว vs กรุงเทพฯ แก้จำนวน/คน/รายได้ได้), "เงิน 1 ล้านกีบ เก็บแบบไหนรักษามูลค่า", ดอกเบี้ยเงินฝาก BCEL vs เงินเฟ้อ |
| เศรษฐกิจลาว | `#/economy` | **10 แท็บสำหรับนักลงทุน** (จำแท็บล่าสุดไว้) เรียงตามคำถามของนักลงทุน: ภาพรวม (ตัวเลขสำคัญ 8 ตัว + สิ่งที่ควรรู้ + ควรจับตาอะไร) · **ประชากร** (มีกี่คน อายุเท่าไร อยู่ที่ไหน ทำงานอะไร: ตัวเลขสำคัญ 8 ตัว, ประชากรถึงปี 2050, โครงสร้างอายุ, พีระมิดอายุ, เทียบเพื่อนบ้าน, 18 แขวง, แรงงานรายภาค, เงินส่งกลับ, สถานะสำมะโน 2025) · GDP & โครงสร้าง (ภาคบริการ/อุตสาหกรรม/เกษตร, การค้า, ดุลบัญชีเดินสะพัด) · แผนรัฐ 2026–2030 (เป้า vs จริง + สถานะอัตโนมัติ) · **นโยบายรัฐ** (ตัวเลขคันโยก 8 ตัว · **กราฟดอกเบี้ยนโยบาย BOL เทียบเงินเฟ้อ** (เส้นขั้นบันได) · กติกาที่ใช้อยู่ 7 เรื่อง: เงินและค่ากีบ, ภาษีและงบประมาณ, น้ำมัน, ค่าแรง, หนี้, การค้า/กติกาต่างประเทศ, ที่ดิน — แต่ละข้อมีวันที่/เลขที่ประกาศ บอกว่ากระทบตัวเลขไหน และปุ่มไปแท็บที่ดูผลได้ · ปฏิทินวันสำคัญ · ค่าคาดการณ์ธนาคารโลกเทียบเป้าแผนรัฐ · ข้อเสนอของธนาคารโลก) · การลงทุนต่างชาติ (รายปี + รายประเทศ) · หนี้สาธารณะ (รายเจ้าหนี้, ตารางชำระหนี้ถึง 2032, ทำไม/ผลกระทบ/แผน/ทำได้ไหม) · เงินเฟ้อ & ค่าเงิน · **ยางพารา 6 มุมมอง** (ปุ่มเลือก จำไว้ให้): *ราคาตลาด* (โลก + ไทย 3 ชนิด เป็นกีบ, รายปี, ราคายางของลาวเองรายปี: ทางการ 2019–2023 และราคาที่ด่านจีน) · *ลาวขายให้ใคร* (จีน/เวียดนาม/ไทย: ปริมาณและราคาที่ด่านรายปี, ราคายางลาวที่ด่านเวียดนามรายเดือนเทียบราคาส่งออกเวียดนามและราคาโลก, ผู้ซื้อรับซื้อเป็นยางชนิดใด, ตัวเลขฝั่งลาวเทียบฝั่งผู้ซื้อ, ตลาดกลางหนองคาย + เชียงรายรายวัน 4 ชนิดยาง) · *ลาว รายแขวง* (พื้นที่ปลูก/พื้นที่กรีดได้ 16 แขวง, ผลผลิตของลาวรายปี) · *อาเซียน + จีน* (**ราคาล่าสุดของแต่ละประเทศ** ลาว ไทย มาเลเซีย เวียดนาม อินโดนีเซีย กัมพูชา เมียนมา ฟิลิปปินส์ จีน โลก — แต่ละแถวบอกชนิดราคาและวันที่ · ส่งออก/นำเข้า ปริมาณ มูลค่า ราคาเฉลี่ย USD/กก. ของ 10 ประเทศ + จีน + ทั้งโลก เลือกปี/ชนิดยางได้ · ผลผลิต พื้นที่กรีด ราคาที่ชาวสวนได้) · *โลก · 10 อันดับ* (ราคาโลก TSR20/RSS3 รายเดือน, 10 อันดับผู้ขาย/ผู้ซื้อ, 10 อันดับผู้ผลิต) · *ราคาที่คุณขายได้เอง* (บันทึกเอง → เทียบตลาดกลางไทยฝั่งที่ใกล้แขวงนั้นที่สุด วันเดียวกัน) · **ที่ดิน** (นครหลวงเวียงจันทน์: ราคาประเมินทางการสรุปราย 9 เมือง × ถนน 4 ประเภท · หลวงพระบาง · ทุกแขวง: วันที่ + ลิงก์เอกสารประเมิน · บันทึกราคาที่เห็นเอง · ราคาซื้อขายจริงยังไม่มีข้อมูลเปิด) — ทุกตัวเลขมีลิงก์แหล่งที่มา ปีของข้อมูล และป้าย ล่าสุด/เก่า |

| ข้อมูล & ตั้งค่า | `#/settings` | สลับภาษา ไทย/ลาว, สลับธีม มืด/สว่าง, **ติดตั้งเป็นแอป** (ปุ่ม + ขั้นตอน), สถานะทุกแหล่งข้อมูล, เวลาอัปเดตล่าสุด |

**สีบอกประเภทตัวเลข** (ทั้งการ์ดและเส้นกราฟ): 🔵 ทางการ · 🟠 ตลาด · 🟢 ค่าประมาณ (เส้นประเมื่ออยู่กับเส้นอื่น) · 🩷 ธนาคาร (LBB, BCEL) · 🟣 ราคาร้าน (กรอกเอง)
**ขึ้น/ลง:** ป้าย ▲ สีเขียว = ขึ้น · ▼ สีแดง = ลง · ▬ สีเทา = ทรงตัว (สีเขียว/แดงใช้กับตัวเลขและลูกศรเท่านั้น ไม่ใช้กับเส้นกราฟ)
**กราฟ:** เส้นโค้งแบบ monotone (ไม่สร้างยอด/หลุมปลอม), พื้นไล่สีใต้เส้นแรก, ป้ายราคาล่าสุดบนแกนขวา, % เปลี่ยนแปลงของช่วงที่เลือก, ช่วง 7 วัน / 1 เดือน / 3 เดือน / 1 ปี / ทั้งหมด · สีทุกชุดตรวจด้วยเครื่องมือตรวจสีสำหรับคนตาบอดสี
**มือถือ:** แถบเมนูล่าง (หน้าหลัก · อัตรา · ทองคำ · ค่าครองชีพ · เพิ่มเติม) — "เพิ่มเติม" คือปุ่มเปิดเมนูเต็ม (มีปุ่มเดียว ไม่มี ☰ ซ้ำที่มุมบน)
**ติดตั้งเป็นแอป:** เว็บนี้ติดตั้งลงหน้าจอมือถือ/คอมพิวเตอร์ได้ (ฟรี ไม่ผ่านสโตร์) → [docs/install-app-th.md](docs/install-app-th.md) · ไม่มีสัญญาณก็เปิดได้: แสดงข้อมูลชุดล่าสุดที่เก็บไว้ในเครื่อง พร้อมป้าย "ออฟไลน์" ที่แถบบน
**ราคาที่บันทึกเอง** (🟣 ป้าย "บันทึกเอง"): ราคายางที่ขายได้ + ราคาที่ดินที่เห็น — กรอกในหน้าเว็บ แล้วเข้าฟอร์ม Google ของเจ้าของ (เว็บนี้เปิดสาธารณะ: ไม่ใส่ชื่อคน เบอร์โทร หรือที่อยู่ละเอียด)

## แต่ละโฟลเดอร์ทำอะไร

| โฟลเดอร์ / ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงแอป: เมนูซ้าย + แถบบน + พื้นที่เนื้อหา |
| `manifest.webmanifest`, `icons/` | ชื่อ สี และไอคอนของแอปเมื่อ "ติดตั้งเป็นแอป" (ไอคอนวาดด้วย `scripts/make-icons.js` ไม่ใช้โปรแกรมอื่น) |
| `sw.js` | service worker: ทำให้ติดตั้งได้ + เก็บสำเนาไฟล์ไว้ใช้ตอนไม่มีสัญญาณ (ถามเครือข่ายก่อนเสมอ ใช้สำเนาเฉพาะเมื่อเครือข่ายล้มเหลวหรือช้าเกิน 4 วินาที) |
| `js/pwa.js` | เปิดใช้ `sw.js` + เก็บ "ข้อเสนอติดตั้ง" ของเบราว์เซอร์ไว้ให้ปุ่มในหน้าตั้งค่า |
| `css/style.css` | หน้าตาเว็บ ธีมมืด/สว่าง (แก้สีได้ที่ `:root` ด้านบนไฟล์) |
| `js/app.js` | ตัวหลัก: โหลดข้อมูล, เปลี่ยนหน้า, เมนู, ภาษา, ธีม |
| `js/pages/*.js` | 1 ไฟล์ต่อ 1 หน้า (overview, rates, gold, living, economy, forecast, settings) · หน้าเศรษฐกิจแยก 1 ไฟล์ต่อแท็บ: `eco-overview.js`, `eco-gdp.js`, `eco-plan.js`, `eco-fdi.js`, `eco-debt.js`, `eco-inflation.js`, `eco-population.js` (ประชากร), `eco-policy.js` (นโยบายรัฐ), `eco-rubber.js` (ยาง 6 มุมมอง) + `eco-rubber-borders.js` (ลาวขายให้ใคร / ราคาแต่ละประเทศ / ตลาดชายแดน) + `eco-rubber-world.js` (อาเซียน/โลก), `eco-land.js` (ที่ดิน), ส่วนกลาง `eco-common.js` · `own-entry.js` = การ์ดบันทึกราคายาง/ที่ดินเอง |
| `js/lazy.js` | โหลดไฟล์ข้อมูลเฉพาะตอนเปิดหน้าที่ใช้ (หน้าแรกบนมือถือจึงเร็ว) |
| `js/ui.js` | ชิ้นส่วนที่ใช้ร่วมกัน: การ์ด, ป้ายสถานะ, ตาราง (เกณฑ์ "ข้อมูลเก่า" อยู่ที่ `MAX_AGE_HOURS`) |
| `js/charts.js` | กราฟ (Chart.js) + แถบค่าเหนือกราฟ (ค่าล่าสุด / ค่าของจุดที่แตะ ใช้แทนกล่องลอยและคำอธิบายสี) + ตาราง "ดูเป็นตาราง" ที่บอกชื่อและหน่วยในหัวตาราง |
| `js/format.js`, `js/icons.js` | รูปแบบตัวเลข/วันที่ (เวลาเวียงจันทน์), ไอคอนเมนู |

- **ราคาที่บันทึกเอง (ยาง/ที่ดิน):** ใช้ฟอร์ม Google เดิมของราคาพูวง (คำถาม 6 ข้อท้ายฟอร์ม ระบบหาจากคำว่า ยาง / ที่ดิน ในชื่อคำถาม) · หน้าเว็บส่งเข้าฟอร์มแล้วอ่าน Sheet กลับเพื่อยืนยันว่าเข้าจริง · ช่องสถานที่เก็บเป็น `<แขวง> | <รายละเอียด>` · ที่ดิน: กรอกเป็นกีบ/บาท/ดอลลาร์ และ ตร.ม./ไร่ (1,600 ตร.ม.)/เฮกตาร์ ได้ หน้าเว็บแปลงเป็นกีบและตารางเมตรด้วยอัตราตลาดวันนั้น และเก็บตัวเลขที่พิมพ์ไว้ในหมายเหตุ · ค่านอกช่วง (ยาง 1,000–200,000 กีบ/กก.; ที่ดิน 50–1,000 ล้านกีบ/ตร.ม.) บอทข้าม · **เว็บและไฟล์ข้อมูลเปิดสาธารณะ**: ห้ามใส่ชื่อคน เบอร์โทร ที่อยู่ละเอียด
- **ที่ดินนครหลวงเวียงจันทน์:** ตารางราคาประเมิน (ข้อตกลง 142, 26 ก.พ. 2024, ฉบับแปลไทยของ ThaiPublica) มี 481 บ้าน × ถนน 4 ประเภท → หน้าเว็บสรุปเป็นรายเมือง (ต่ำสุด / ค่ากลาง / สูงสุด) ไม่คัดลอกทั้งตาราง และลิงก์ไป PDF ต้นฉบับ · แต่ละเมืองมีลิงก์ "เอกสารหน้า N" (`...pdf#page=N`, เลขหน้าอยู่ใน `land.vientiane.districts[].page`) เปิดเอกสารต้นทางที่หน้าที่เมืองนั้นเริ่ม แล้วหาบ้านของตัวเองด้วย "ค้นหาในหน้า" ของเบราว์เซอร์ — ตารางรายบ้านเป็นฉบับแปลของ ThaiPublica จึงไม่คัดลอกมาทำช่องค้นหาในเว็บ · **หลวงพระบาง:** ยังไม่พบเอกสารราคาประเมินออนไลน์ (ไม่อยู่ในราชกิจจานุเบกษา ณ 1 ต.ค. 2026) หน้าเว็บบอกตรง ๆ

## สูตรสำคัญ
- **ทองลาวประมาณการ** = ราคาทองแท่งไทย × THB→LAK ตลาด (ต่อ 1 บาทไทย 15.244 ก.)
- **ราคาทองลาวจริง** = ราคาขาย LBB ต่อกรัม × 15 (ต่อ 1 บาทลาว)
- **พรีเมียม** = ราคาขาย LBB ÷ ค่าประมาณ (วันเดียวกัน) — รวมส่วนต่างความบริสุทธิ์และหน่วยบาทไทย/ลาวไว้แล้ว
- **ประมาณการปรับพรีเมียม** = ค่าประมาณ × พรีเมียมเฉลี่ย 14 วัน**ก่อนหน้า** (ไม่ใช้ราคาวันเดียวกัน) · % คลาดเคลื่อนในหน้าพยากรณ์วัดเทียบ LBB
- **ราคาไทยเป็นกีบ** = ราคาบาท × THB→LAK ตลาด · **ลาวเทียบไทย %** = (ลาว − ไทย) ÷ ไทย × 100 (บวก = ลาวแพงกว่า)
- **ราคาอาหารไทยต่อวัน** = (ต่ำสุด + สูงสุด) ÷ 2 ของวันนั้น (ข้าวสารประกาศต่อ 15 กก. → หาร 15)
- **ดอกเบี้ยหลังหักเงินเฟ้อ** = (1 + ดอกเบี้ย) ÷ (1 + เงินเฟ้อ) − 1
- **ราคายางลาวที่ด่านจีน USD/กก.** = มูลค่านำเข้า (CIF, USD) ÷ น้ำหนักสุทธิ (กก.) ของ HS 4001 ที่จีนนำเข้าจากลาวทั้งปี · เป็นกีบ = × อัตราเฉลี่ยของปีนั้น
- **ราคาเฉลี่ยส่งออก/นำเข้ายางของแต่ละประเทศ USD/กก.** = มูลค่า (USD) ÷ น้ำหนักสุทธิ (กก.) ของปีนั้น เฉพาะส่วนที่มีน้ำหนัก (ส่งออก = FOB ที่ด่านผู้ขาย · นำเข้า = CIF รวมค่าขนส่ง)
- **ราคายางที่บันทึกเอง เทียบไทย %** = ราคาที่ขายได้ (กีบ/กก.) ÷ ราคาตลาดไทยชนิดเดียวกันของวันนั้น (บาท × THB→LAK ตลาด) × 100 — ยางก้อนถ้วยของไทยเป็นราคาเนื้อยางแห้ง 100% ยางเปียกจึงต่ำกว่าเป็นปกติ
  · ตลาดที่ใช้เทียบ = ตลาดกลางที่ใกล้แขวงนั้นที่สุด: บ่อแก้ว หลวงน้ำทา อุดมไซ ผ้งสาลี ไซยะบูลี หลวงพระบาง → **เชียงราย** · แขวงอื่น → **หนองคาย** (วันเดียวกัน หรือวันทำการล่าสุดก่อนหน้า) ถ้าไฟล์รายวันยังไม่มี ใช้ราคากระทรวงพาณิชย์ไทยเหมือนเดิม
- **ราคายางลาวที่ด่านเวียดนาม USD/กก.** = มูลค่า (USD) ÷ น้ำหนัก (ตัน × 1,000) ของแถว "Cao su" ที่นำเข้าจากลาวในเดือนนั้น (ตาราง 5N ของศุลกากรเวียดนาม) · ยอดทั้งปี = คอลัมน์ "สะสมตั้งแต่ต้นปี" ของไฟล์เดือนล่าสุดของปีนั้น
- **ราคายางแต่ละประเทศเป็น USD/กก.** = ราคาเงินท้องถิ่น ÷ อัตราตลาดของวันนั้น (บาท ริงกิต เปโซ) · เซี่ยงไฮ้: หยวน/ตัน ÷ อัตรา ÷ 1,000
- **ราคาที่ดินที่บันทึกเอง กีบ/ตร.ม.** = ราคารวม (แปลงเป็นกีบ) ÷ เนื้อที่ (ตร.ม.; 1 ไร่ = 1,600 · 1 เฮกตาร์ = 10,000)
- **ราคายางโลก USD/กก.** = ราคา IMF (เซนต์สหรัฐต่อปอนด์) × 2.20462 ÷ 100 · เป็นกีบ = × อัตรา BOL เฉลี่ยของเดือน/ปีนั้น (ก่อนมีข้อมูล BOL ใช้อัตราเฉลี่ยรายปีของธนาคารโลก)
- **กีบอ่อนค่าเทียบปีก่อน (%)** = (อัตรา BOL USD เฉลี่ยเดือนนี้ ÷ เดือนเดียวกันปีก่อน − 1) × 100
- **สัญญาณค่ากีบ**: ทุกวันทำการ ก่อน BOL ประกาศ → ดูอัตราตลาดวันนี้เทียบวันก่อน → บันทึก ▲▼▬ (แก้ย้อนหลังไม่ได้)
  เมื่อ BOL ประกาศ → เทียบค่ากลาง (ซื้อ+ขาย)/2 กับวันประกาศก่อนหน้า → ถูก/ผิด · เปลี่ยนน้อยกว่า 0.02% = ทรงตัว
- **% ความแม่นยำ** คำนวณในหน้าเว็บจากไฟล์ประวัติที่บันทึกไว้เท่านั้น ไม่มีตัวเลขตายตัว

node scripts/fetch-rubber-daily.js  # ราคายางรายวัน: หนองคาย/เชียงราย, มาเลเซีย, เซี่ยงไฮ้ (เติม months=14 = ย้อนหลัง 14 เดือน)
node scripts/fetch-rubber-borders.js  # ใครซื้อยางลาว + ราคาที่ด่าน (~1.5 นาที; เติม all = อ่านศุลกากรเวียดนามใหม่ทุกเดือน ~20 นาที)

> ⚠️ ห้ามเปิด `index.html` ด้วยการดับเบิลคลิก เพราะเบราว์เซอร์จะไม่ยอมให้อ่านไฟล์ข้อมูล ให้ใช้ `serve.js`

### ทดสอบ
- **ทดสอบหน้าเว็บในเบราว์เซอร์จริง** (ต้องมี Edge หรือ Chrome; Node 22 ขึ้นไป):
  ```bash
  node tests/all.js            # ทุกอย่างในเครื่อง ~20 นาที (เติม quick = ตรวจ 21 หน้าจอแทน 168)
  node tests/screens.js quick  # เฉพาะหน้าจอ: ไทย มืด มือถือ (~1 นาที)
  node tests/live.js           # เว็บจริงบน GitHub Pages หลัง push 2–3 นาที (รวมจำลองสัญญาณหลุด)
  ```
  ตรวจ: ไม่มีการเลื่อนซ้าย-ขวา, ไม่มีอะไรล้นจอ, ไม่มีคำว่า undefined / NaN / `{ตัวแปร}` ที่ไม่ถูกแทนค่า, กราฟถูกวาดครบ, ไม่มี error ใน console, ติดตั้งเป็นแอปได้, ออฟไลน์เปิดได้พร้อมป้าย · รูปหน้าจอเก็บใน `tests/shots/` (ไม่ commit) · ฟอร์มบันทึกราคาถูกเปิดและกรอก แต่**ไม่กดบันทึก** และคำขอไป Google ถูกบล็อกระหว่างทดสอบ จึงไม่มีแถวปลอมเข้า Sheet
- **แหล่งข้อมูลพัง:** `GOLD_THAI_URL=https://invalid.example GOLD_THAI_BACKUP_URL=https://invalid.example node scripts/fetch-all.js` (ใช้ Git Bash)
  → เฉพาะทองไทยเป็น FAIL + ป้ายข้อมูลเก่า แหล่งอื่นยังปกติ
  ตัวแปรที่ใช้ได้: `BOL_URL`, `GOLD_WORLD_URL`, `GOLD_WORLD_BACKUP_URL`, `GOLD_THAI_URL`, `GOLD_THAI_BACKUP_URL`, `FX_MARKET_URL`, `BOL_BACKFILL_URL`, `GOLD_LBB_URL`, `LBB_BACKFILL_URL`, `BCEL_URL`, `BCEL_DEPOSIT_URL`, `LAO_GOLD_CSV_URL`, `RAOT_URL`, `LGM_URL`, `SHFE_URL`
- **ทดสอบโดยไม่แตะข้อมูลจริง:** `DATA_DIR=<โฟลเดอร์ทดสอบ>` เปลี่ยนที่เก็บข้อมูล · `SITE_ROOT=<โฟลเดอร์>` ให้ `serve.js` เปิดเว็บจากโฟลเดอร์อื่น
- **จำลองเวลา (สัญญาณค่ากีบ):** `NOW=2026-09-29T08:00:00+07:00 node scripts/update-forecast.js`

## รูปแบบข้อมูล

ทุกค่าใช้รูปแบบเดียวกัน:
```json
{ "source": "bol", "metric": "USD_LAK_buy", "value": 22329, "unit": "LAK per USD",
  "fetched_at": "2026-09-29T11:08:58Z", "source_date": "2026-09-28" }
```
- ค่าซ้ำ (metric + source_date เดิม) จะไม่ถูกเพิ่มใน history · ราคาพูวงสร้าง history ใหม่จาก Sheet ทุกครั้ง (แก้ใน Sheet ได้)
- ไฟล์จะถูกเขียนใหม่ **เฉพาะเมื่อค่าเปลี่ยน** เพื่อให้ GitHub commit เฉพาะตอนมีข้อมูลใหม่

## ขั้นตอนขึ้น GitHub (ทำแล้ว 29 ก.ย. 2026 — เก็บไว้เป็นบันทึก)

1. สมัคร/ล็อกอิน https://github.com แล้วกด **New repository** (ตั้งเป็น Public เพื่อใช้ GitHub Pages ฟรี)
2. ในโฟลเดอร์นี้ พิมพ์:
   ```bash
   git add .
   git commit -m "Lao Kip & Gold dashboard"
   git branch -M main
   git remote add origin https://github.com/<ชื่อคุณ>/<ชื่อ-repo>.git
   git push -u origin main
   ```
3. บน GitHub: **Settings → Actions → General → Workflow permissions** เลือก **Read and write permissions**
4. **Actions → Fetch data → Run workflow** และ **Fetch economy data → Run workflow** เพื่อทดสอบ
5. **Settings → Pages** → Source: *Deploy from a branch* → Branch `main` / `(root)`

หมายเหตุ: ตาราง cron ของ GitHub อาจเริ่มช้ากว่ากำหนด 10–30 นาทีในบางช่วง
